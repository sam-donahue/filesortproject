# File Sort Project

In this project we have created a program that takes a batch of filenames (found in samplefiles.txt), and sorts those files based on the choice that the user makes. The user is able to sort files by student name, date, and subject; whichever choice the user makes the files will be sorted the way they would like. We havae made this with scalibliity in mind, so we have gived the user the ability to also add in new file names that would be added to the batch and sorted with the rest.
